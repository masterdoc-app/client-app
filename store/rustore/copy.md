# Fixaverse — тексты для RuStore Console

Скопируйте поля в [console.rustore.ru](https://console.rustore.ru) при загрузке версии.

## Название (≤50 символов, ASO)

```
Fixaverse — заявки для инженера
```

## Краткое описание (≤80)

```
Заявки, доска, карта коллег, оборудование и ППР — приложение инженера.
```

## Полное описание

```
Fixaverse — мобильный клиент инженера на объекте. Работайте с заявками, следите за доской недели и картой коллег, открывайте паспорт оборудования и карты ППР без лишних переходов.

Возможности:
• Заявки — список работ, статусы и детали на месте
• Доска и карта — план недели и инженеры на линии
• Оборудование — паспорт, документы и привязка к площадке
• ППР — карты обслуживания и регламенты в базе

Приложение для сотрудников обслуживающих организаций. Требуется корпоративный аккаунт Fixaverse.
```

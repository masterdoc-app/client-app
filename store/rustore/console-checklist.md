## Перед загрузкой

- [ ] Создать или выбрать приложение Fixaverse в RuStore Console
- [ ] Проверить package: `pro.masterdoc.client`
- [ ] Загрузить `icon-512.png`
- [ ] Загрузить оба скриншота 1080×1920 и проверить crop в превью
- [ ] Вставить название, краткое и полное описание из `copy.md`
- [ ] Выбрать категорию «Инструменты» и рейтинг `0+`
- [ ] Указать приложение как бесплатное
- [ ] Добавить ссылку на действующую политику конфиденциальности организации
- [ ] Указать контакт поддержки организации
- [ ] Проверить разрешения: приложению нужен доступ к интернету; другие разрешения должны соответствовать фактическому AAB

## Загрузка версии

- [ ] Собрать подписанный release AAB в CI
- [ ] Загрузить AAB версии `pro.masterdoc.client`
- [ ] Вставить текст «Что нового» из `copy.md`
- [ ] В комментарии модератору указать корпоративный сценарий и вход по организации
- [ ] Проверить, что в пользовательских текстах нет UUID или внутренних идентификаторов
- [ ] Отправить версию на модерацию

## После публикации
